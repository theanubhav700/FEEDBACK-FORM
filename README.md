# HEXA — Judge Feedback System
### Indian Data Club (IDC) Hackathon 3.O

Official Judge Evaluation & Feedback terminal built for **Team HEXA** at **IDC Hackathon 3.O**.

---

## ⚡ Features

* **Cyber-Tech Terminal UI**: Clean dark and high-contrast light theme with instant toggle.
* **Interactive Star Rating**: 1–5 stars evaluation with instant numeric and label feedback.
* **Form Validation**: Clean inline validation for Judge Name, Star Rating, and Written Feedback.
* **Persistence**: Browser `localStorage` persistence under key `idc_hackathon_3_feedback`.
* **Zero Backend Overhead**: Lightweight, ultra-fast client-side application.
* **Fully Responsive**: Optimized for desktop, tablet, and mobile viewports.

---

## 🛠 Tech Stack

* **React 19**
* **Vite**
* **Modern CSS & CSS Variables**
* **Local Storage**

---

## 🚀 Running Locally

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
